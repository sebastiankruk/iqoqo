## Purpose

Updates architecture documentation to include the Semantic Web layer, public API design, and SPARQL endpoint security model, enabling developers to understand the system architecture for Linked Open Data features.

## Requirements

### Requirement: Semantic Web layer architecture documented
The ARCHITECTURE.md SHALL include a section on Semantic Web layer architecture.

#### Scenario: Semantic Web layer in ARCHITECTURE

- **WHEN** developer reads ARCHITECTURE.md
- **THEN** Semantic Web layer architecture is documented with components and data flow
