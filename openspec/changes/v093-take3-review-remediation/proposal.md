## Why

The full-branch Take 3 Principal Code Review of `release/0.9.3` (`main..ac85446`) uncovered 7 immediate release-blocking defects alongside 20 moderate and 20 low-severity security, concurrency, schema-drift, localization, and test-coverage issues across SSE/Gunicorn worker concurrency, BFF `X-Forwarded-Host` origin parsing, ActivityPub port-preserving trust enforcement, background PostgreSQL FTS re-indexing, PAT/TOTP authentication, OpenAPI 3.1 contract generation, and developer documentation. Resolving all outstanding findings in a unified pre-tag remediation change (`C87e`) ensures `v0.9.3` ships with zero known security bypasses, worker deadlocks, no-op background tasks, or contract drift.

## What Changes

- **SSE Gunicorn Concurrency, Authenticated Stream Gating & Real Background FTS Re-indexing (`docker-compose.yml`, `app/api/events.py`, `app/core/events.py`, `app/core/tasks.py`, `app/api/items.py`, `app/api/lending.py`, `app/api/manifestations.py`, `frontend/components/providers.tsx`)**:
  - Switch Gunicorn in `docker-compose.yml` from `--worker-class sync --threads 1` to `--worker-class gthread --threads ${GUNICORN_THREADS:-8}` so concurrent SSE streams cannot starve API workers or trigger 30s `SIGABRT` worker timeouts.
  - Clamp `GET /api/v1/events/stream` `timeout` strictly below `GUNICORN_TIMEOUT` (`[1.0, 20.0]` seconds, default `20.0s`), fail closed in `_should_deliver_event` when `user_id is None`, reuse a pooled/cleanly closed Redis connection across `events.py` and `tasks.py`, and gate `TransitionEventsListener` so `EventSource` only connects when an authenticated session is active on non-public routes.
  - Replace the no-op `batch_fts_reindex` implementation with real PostgreSQL `Work.search_vector` (`to_tsvector`) SQL recomputation across affected `work`, `manifestation`, and `item` entries, gate `apply_async` with a Redis `SET iqoqo:fts_reindex_scheduled 1 NX EX 5` debounce lock and `threading.Lock` on `_in_memory_fts_queue`, scope `fts_reindexed` SSE invalidations to affected owners instead of triggering global cross-tenant cache stampedes, skip `enqueue_fts_reindex` on already-deleted primary keys, and hoist repeated inline transition imports.
- **BFF Open Redirect Fix, PAT Scope Parity, `optional_auth` Throttling & TOTP Hardening (`frontend/app/api/auth-exchange/route.ts`, `app/api/decorators.py`, `app/api/auth.py`, `app/db/auth.py`, `frontend/components/profile/pat-management.tsx`, `frontend/components/profile/totp-setup.tsx`, `frontend/app/login/page.tsx`, `frontend/messages/en.json`, `frontend/messages/pl.json`)**:
  - Harden `isAllowedHost` and `resolveFrontendOrigin` in `frontend/app/api/auth-exchange/route.ts` via strict `URL` parsing (rejecting `@` userinfo, paths, queries, fragments, commas, and backslashes) and canonical host reconstruction to eliminate `X-Forwarded-Host` open redirects.
  - **BREAKING (Security)**: Remove raw long-lived `?token=` query-string JWT/PAT extraction on `/api/v1/events/stream` in `app/api/decorators.py` so bearer secrets cannot leak into reverse-proxy access logs (clients authenticate via `HttpOnly` session cookies or `Authorization: Bearer`).
  - Throttle `pat.last_used_at` commits to once per 60 seconds and enforce `read:catalog` / `read:*` / `admin` / `*` scope validation inside `optional_auth`; permit `"curator"` PAT scope creation for `contributor`/`custodian`/`admin` roles in `create_token`, allow `"sparql:query"` on `POST /api/sparql` in `require_auth`, and map `"write:inventory"` alongside `"write:catalog"` in `require_permission`.
  - Prevent RFC 6238 TOTP code replay within the 90-second acceptance window, add rate-limiting on `POST /api/auth/2fa/enroll` and per-account OTP failure throttling without penalizing two-step MFA logins, and write `EntityAuditLog` entries when enabling or disabling 2FA.
  - Filter `admin` and `*` PAT scope checkboxes for non-admin users in `PatManagement`, wire `useTranslations("Profile")` (`en.json` and `pl.json`) into `PatManagement` and `TotpSetup`, and remove the duplicate blocking `window.alert()` in `frontend/app/login/page.tsx`.
- **ActivityPub Port-Preserving Trust Enforcement, Follow Consent, DER Fingerprints & Admin Key Lifecycle (`app/api/federation.py`, `app/core/federation_handlers.py`, `app/core/federation_sync.py`, `app/core/federation_keys.py`, `app/core/federation_discovery.py`, `app/api/admin.py`, `frontend/components/admin/instance-settings.tsx`, `docker-compose.federation-preview.yml`, `scripts/iqopretest.sh`)**:
  - Replace all 6 residual `urlparse(...).hostname` port-stripping lookups with `clean_instance_domain(...)` in `receive_inbox`, `handle_create`, `handle_update`, `handle_delete`, `handle_announce`, and `reconcile_activity`.
  - Fix `handle_follow` so auto-acceptance strictly requires `bool(auto_accept and instance and instance.trust_level == TrustLevel.TRUSTED)` (never auto-accepting when `FEDERATION_AUTO_ACCEPT_FOLLOWS=False` and never auto-accepting `UNTRUSTED` peers when `True`), while preserving existing `ACCEPTED` and `REJECTED` follow states on duplicate `Follow` activities.
  - Compute `SHA256:...` public key fingerprints from decoded ASN.1 DER `SubjectPublicKeyInfo` bytes in `compute_pem_fingerprint`, filter peer `FederationActor` fingerprint lookups strictly to canonical `/api/federation/actor` URIs, validate same-origin `clean_instance_domain(instance_actor_url) == instance.domain` in `probe_instance_health`, pop `instance_actor_url` and refresh instance actor keys in `probe_registered_instances`, and harden `is_publicly_routable_peer_domain` for IPv6 brackets and `.localdomain`/`.home.arpa`/`.lan`.
  - Make `PUT /api/v1/admin/settings` (`_put_settings`) two-phase atomic so invalid or unauthorized keys abort the entire payload before mutating `InstanceSettings`, treat `"Not configured"` as unprovisioned in `instance-settings.tsx` with a confirmation dialog before live key rotation, bind `peer-frontend` to `127.0.0.1` in `docker-compose.federation-preview.yml`, and replace the fixed `sleep 30` in `scripts/iqopretest.sh` with health-endpoint polling.
- **Bounded RDF Export, BGG2/IGDB Resilience, Zero-Drift OpenAPI 3.1, Developer Docs & Regression Suites (`app/core/export_service.py`, `app/api/public_rdf.py`, `app/utils/bgg.py`, `app/utils/igdb.py`, `app/api/docs.py`, `frontend/next.config.ts`, `scripts/iqoqo-status.sh`, `docs/API.md`, `docs/CHANGELOG.md`, `docs/gems/iqoqo-librarian-gem.md`, `requirements.txt`, `pyproject.toml`, `tests/*`, `frontend/__tests__/*`)**:
  - Add `joinedload(Item.borrower)` and bounded chunked SQL iteration to `ExportService.export_rdf`, enforce explicit `Item.visibility == "public"` alongside `Item.is_hidden.is_(False)` in public RDF/instance counts, use `clean_instance_domain` in `get_public_federation_instance_info`, and add `Referrer-Policy: no-referrer` on `/share/:path*` in `frontend/next.config.ts`.
  - Pin `boardgamegeek2>=1.0.1`, cap `Retry-After` sleep at `10.0s`, set `retries=0` on `BoardGameGeek` client when mounted with `BGGBackoffAdapter`, fall back to `InstanceSettings.get_value("BGG_API_TOKEN")`, write `.igdb_token.json` atomically via sibling temp file + `os.replace()` with sanitized error reasons, and pass `IQOQO_ROOT` / `IGDB_CLIENT_ID` via environment variables in `scripts/iqoqo-status.sh`.
  - Align `app/api/docs.py` with UUID types (`User.id`, `Item.owner_id`, `Notification.recipient_id`), accurate `PersonalAccessToken` (`is_active`, `revoked_at`) and `Notification` (`payload`, `actor_uri`) schemas, `rule._converters` path parameter inference, and `_requires_auth = True` decorator metadata; rewrite inaccurate 2FA/login/SSE/Swagger sections in `docs/API.md`, fix `PATCH /api/v1/notifications/read` in `docs/CHANGELOG.md`, and sync `/api/scanner/preview/{barcode}` in `docs/gems/iqoqo-librarian-gem.md`.
  - Upgrade `tests/test_async_fts_transitions.py` (SQLAlchemy 2.0 + real `Work.search_vector` assertions), extend `pat_and_totp_workflow.spec.ts` to exercise `/profile` PAT lifecycle, and add comprehensive regression tests across backend, Vitest, and BATS suites.
