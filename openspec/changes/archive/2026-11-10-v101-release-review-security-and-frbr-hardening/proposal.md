# Proposal: v1.0.1 Release Review Remediation — Security, Rebrickable SSRF/N+1, LEGO FRBR Columns & UX Hardening (`C108c`)

## Why

The unified Principal & Gemini Release Review of `release/1.0.1` (`.context/notes/review/1.0.1/principal-full-release-1.0.1-review.md` and `.context/notes/review/1.0.1/review-release-1.0.1-pr-405.md`, PR [#405](https://github.com/sebastiankruk/iqoqo/pull/405)) identified **4 Critical (`C-01`–`C-04`)** and **7 Moderate (`M-01`–`M-07`)** issues across the newly folded `C101`–`C108b` deliverables that must be resolved before merging `v1.0.1` into `main`:

1. **`C-01` (Critical — Security / Stored XSS, Filename Collisions & Missing Per-Attachment `scale`/`projection`)**: `POST /api/manifestations/<id>/map-attachments` accepts unsanitized `image_url` strings (including `javascript:` and `data:` URIs), names uploaded files `manifestation_{id}_map_{file.filename}` before generating `attachment_id` (causing mobile `image.jpg` uploads to overwrite previous maps), omits `scale`/`projection` from the `attachment` dict read by `MapViewerModal`, resets `has_map` to `False` on `DELETE` even for standalone `cartographic_map`/`atlas` manifestations, and allows unbounded `title`/`scale`/`projection` strings into shared `Manifestation.meta["map_attachments"]` without count limits or `EntityAuditLog` tracking, while `MapViewerModal` renders `<a href={imageUrl} target="_blank">` without scheme validation.
2. **`C-02` (Critical — Security / Rebrickable Path Traversal & 21-Call Synchronous Waterfall)**: `normalize_set_number()` in `app/utils/rebrickable.py` returns arbitrary non-numeric strings unchanged, which `fetch_rebrickable_set()` and `_fetch_minifig_count()` interpolate directly into `https://rebrickable.com/api/v3/lego/sets/{normalized}/` carrying the server's `REBRICKABLE_API_KEY`. Additionally, `search_rebrickable_sets()` triggers 2 synchronous HTTP calls per candidate (up to 21 sequential HTTP calls per search, hitting Rebrickable's 1 req/s HTTP 429 limit), and `_THEME_CACHE` is unbounded.
3. **`C-03` (Critical — FRBR Data Integrity, LEGO Deduplication, Year-vs-Set-Number Regex & `570201` Barcode Routing)**: `IngestService.ingest_lego_from_barcode()` does not deduplicate existing `Manifestation` rows by barcode/`set_number` and omits first-class SQL columns `Manifestation.ean`, `Manifestation.upc`, `Manifestation.format`, `Manifestation.format_type`, and `Manifestation.cover_url`; `IngestService.ingest_from_meta()` drops LEGO `Work.meta["theme"]` and `Manifestation` set fields; `re.search(r"\b(\d{4,6})\b", title)` in `app/strategies/lego.py` matches 4-digit release years (`2024`) as LEGO set numbers; and `570201xxxxxxx` LEGO GS1 barcodes scanned when the UI defaults to `?format=book` have `effective_category` locked to `"text"` before the `570201` check runs.
4. **`C-04` (Critical — FRBR F5 -> F3 Boundary Violation on LEGO Item Edits)**: `EditItemForm` (`frontend/components/item/edit-item-dialog.tsx`) sends Item-level LEGO fields (`build_status`, `missing_pieces_count`, `instructions_included`) inside `payload.meta`, which `_update_physical_item` (`app/api/items.py`) merges into **both** `manifestation.meta` (F3) and `item.meta` (F5) — violating `iqoqo-shapes.ttl` (`iqoqo:buildStatus cannot be attached to a Manifestation; it belongs to an Item`) and polluting shared catalog metadata across users.
5. **`M-01` (Moderate — SRE / Database Operations)**: `scripts/verify_ai_cover_bindings.py` uses `OFFSET` pagination instead of keyset pagination (`Manifestation.id > last_id`), and `make fix-ai-covers prod` passes `-T` to `docker compose exec` without forwarding `ALLOW_PROD_REPAIR`, causing interactive `input()` confirmation to crash with `EOFError`.
6. **`M-02` (Moderate — Taxonomy Normalizer)**: `app/core/format_normalizer.py` omits `UNKNOWN_LEGO`, `UNKNOWN_BOARD_GAME`, `UNKNOWN_PUZZLE`, and `UNKNOWN_AUDIOBOOK` from `_category_to_unknown_placeholder` and `_UNKNOWN_FORMATS`.
7. **`M-03` (Moderate — Security / SQL Pagination & FRBR Class Option)**: `NewMediaTypeEscalationPayload.suggested_properties` has no list/string bounds or text sanitization, `validate_frbr_class` and `<RequestNewTypeModal />` omit `F3_Manifestation_Product_Type` (documented in Curators' Handbook), `POST /api/escalations` lacks `@limiter.limit`, and `GET /api/escalations/mine` & `GET /api/escalations/queue` execute unpaginated `.all()` queries.
8. **`M-04` (Moderate — Federation Peering Accuracy)**: `get_federation_instances` loads all `FederationActivity.actor_uri` rows into memory without `distinct()` and uses unanchored substring matching (`domain_lower in uri.lower()`), `add_federation_instance` hardcodes `has_inbound=False`, and `compute_peering_direction` (`app/core/federation_discovery.py`) marks `"untrusted"` peers as `"reciprocal"` whenever inbound traffic exists.
9. **`M-05` (Moderate — System Status Parity)**: `REBRICKABLE_API_KEY` is missing from `GET /api/system/status` (`app/api/system.py`) and `scripts/iqoqo-status.sh` (`make status`), and `system_status` makes ~13 individual `InstanceSettings.get_value()` queries instead of reusing `InstanceSettings.get_configured_keys()`.
10. **`M-06` (Moderate — OpenAPI 3.1 Contract)**: `app/api/docs.py` has an outdated `Expression.content_type` enum (missing `lego`, `board_game`, `puzzle`) and untyped map attachment / new media type escalation endpoints.
11. **`M-07` (Moderate — Map Viewer, `/manifestation/[id]` Wiring & Facet UX)**: `manifestation-detail-client.tsx` does not pass `manifestationId` or `canEdit` to `<ExtendedMetadata />`, `/api/stats/facets` ignores `has_map`, `ExtendedMetadataMaps` lacks a Delete button for existing attachments and omits `scale`/`projection` inputs in its upload modal, and `MapViewerModal` lacks keyboard shortcuts (`+`, `-`, `r`, `0`, `ArrowLeft`, `ArrowRight`).

## What Changes

- **Map Attachment Security & UX (`C-01`, `M-07`)**:
  - Harden `POST` and `DELETE /api/manifestations/<id>/map-attachments` (`app/api/manifestations.py`) with strict URL validation (`/static/gallery/...` or SSRF-safe `http(s)://`), length caps (`title <= 200`, `scale <= 100`, `projection <= 100`, `image_url <= 500`), attachment count cap (`<= 20`), and `EntityAuditLog` entries.
  - Harden `MapViewerModal` (`frontend/components/item/map-viewer-modal.tsx`) against non-`http(s)` / non-`/` URLs and add keyboard shortcuts (`+`/`=`, `-`, `r`, `0`, `ArrowLeft`, `ArrowRight`).
  - Add a Delete attachment button and `Scale`/`Projection` modal inputs to `ExtendedMetadataMaps` (`frontend/components/item/extended-metadata-maps.tsx`).
- **Rebrickable Path-Traversal Guard & N+1 Elimination (`C-02`)**:
  - Enforce `_VALID_SET_NUM_RE = re.compile(r"^\d{3,7}(?:-\d{1,2})?$")` and `urllib.parse.quote(normalized, safe="")` in `app/utils/rebrickable.py`, skip per-candidate `_fetch_minifig_count()` calls during multi-set `search_rebrickable_sets()`, and bound `_THEME_CACHE` to 512 entries.
- **LEGO FRBR Ingestion & `570201` Barcode Priority (`C-03`, `M-02`)**:
  - Populate `Manifestation.ean`, `Manifestation.upc`, `Manifestation.format_type`, `Expression.content_type = MediaCategory.LEGO`, and `Work.meta["theme"]` consistently in both `IngestService.ingest_lego_from_barcode()` and `IngestService.ingest_from_meta()` (`app/core/ingest.py`).
  - Prioritize `570201xxxxxxx` LEGO GS1 barcodes in `app/api/scanner.py` even when `format_hint` defaults to `"book"`.
  - Complete `_category_to_unknown_placeholder` and `_UNKNOWN_FORMATS` in `app/core/format_normalizer.py`.
- **Escalation Bounds, Federation Peering, AI Cover Keyset Pagination, Status Parity & OpenAPI 3.1 (`M-01`, `M-03`, `M-04`, `M-05`, `M-06`)**:
  - Switch `verify_and_repair_ai_covers()` (`scripts/verify_ai_cover_bindings.py`) to keyset pagination and make `Makefile` `fix-ai-covers` TTY-aware.
  - Bound & sanitize `suggested_properties`, add `@limiter.limit("10 per minute")`, and paginate `list_my_escalation_requests` / `list_escalation_queue` (`app/api/social.py`).
  - Use distinct host-anchored matching for `has_inbound_activity` across `get_federation_instances`, `add_federation_instance`, and `update_instance_trust` (`app/api/admin.py`).
  - Add `rebrickable` (`REBRICKABLE_API_KEY`) to `app/api/system.py` and `scripts/iqoqo-status.sh`.
  - Update `app/api/docs.py` with canonical `Expression.content_type` enum values and map-attachment / escalation request & response schemas.
