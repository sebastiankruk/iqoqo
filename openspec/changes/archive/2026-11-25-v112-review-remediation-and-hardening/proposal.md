## Why

The consolidated Principal and Neon (`PR #453`) release review of `release/1.1.2` identified 3 critical regressions, 8 moderate hardening gaps, and 9 low-severity polish items across cross-media `Work` linking, FRBR merge/ETL collision handling, full-library graph edges, PostgreSQL manifestation FTS, offline collection filtering, and LOD RBAC. Remediating these defects in `C152` before tagging `v1.1.2` prevents `UniqueViolation` merge crashes, fixes broken manual Work-link creation, bounds synchronous Ollama worker latency, and restores strict contract parity across backend, frontend, ontology, and docs.

## What Changes

- **Fix Critical Manual Work-Link Search Envelope & Debounce (`WorkLinkReviewer`):** Replace imperative per-keystroke `apiClient.get` (`res.data?.results` envelope bug) in `frontend/components/admin/work-link-reviewer.tsx` with `useDebounce` and `useCatalogGraphSearch(..., "work", 8)` reading `res.data?.data ?? []`, restoring manual source/target `Work` selection and `"Create link"` while eliminating keystroke request floods.
- **Fix Critical FRBR Merge Reversed-Pair `WorkLinkCandidate` Collision (`app/core/frbr_merge.py`):** Pre-prune `WorkLinkCandidate` rows attached to `source_id` whose peer `Work` `C` already shares a candidate with `target_id` in either direction (`(target_id, C)` or `(C, target_id)`) before `RefPoint` repointing, preventing `UniqueViolation` on unordered `uq_work_link_candidates_pair`.
- **Fix Critical ETL Raw-SQL Third-Party Work Merge Collisions (`scripts/etl/merge.py`):** Delete colliding third-party `work_relations` rows (matching `(target, C, relation_type)` or `(C, target, relation_type)`) and colliding third-party `work_link_candidates` rows (matching unordered `(target, C)` or `(C, target)`) in `apply_work_merge_plan()` prior to executing raw `UPDATE` statements.
- **Harden Cross-Media Ollama Config, `ALLOW_LLM`, SSRF Redirects & Sync HTTP Scan Budget (`app/core/work_linking_service.py`, `app/api/admin.py`):** Resolve `OLLAMA_URL` (with Docker `host.docker.internal` fallback) and `OLLAMA_DEDUPE_MODEL` via `ConfigService`, honor `ALLOW_LLM` (`_is_llm_enabled()`), set `allow_redirects=False` on Ollama HTTP requests, and bound synchronous HTTP scan LLM calls with a low sync cap and strict wall-clock budget (`<= 15s`) so Gunicorn workers cannot `504` or starve.
- **Fix Cross-Media Derivation Rank & Atomic Candidate Acceptance (`app/core/work_linking_service.py`):** Add `"text": 1`, `"audiobook": 2`, and canonical `shared/taxonomy.yaml` category keys to `_MEDIA_DERIVATION_RANK` so book adaptations never invert `source`/`target`; make `accept_candidate()` single-commit atomic (`create_work_relation(..., commit=False)`), reject already-resolved (`status != "pending"`) candidates with HTTP `409`, and verify any `source_work_id`/`target_work_id` override equals `{candidate.source_work_id, candidate.target_work_id}`.
- **Complete Graph `"derivatives"` Library Edges & Balanced Root Search (`app/core/graph_service.py`, `app/api/works.py`):** Emit accepted `WorkRelation` (`"derivatives"`) edges in `build_library_graph()` when `"derivatives"` is active; allocate balanced per-type quotas (`max(1, effective_limit // len(requested))` with backfill to `effective_limit`) in `search_root_candidates()`, deduplicate `series` `Work` IDs from the `work` pass, and restrict `ent_type == "person"` to `Contributor.type == "person"` (or `NULL`); cap `_expand_work()` `WorkRelation` queries to `MAX_GRAPH_NODES` and bound `q` length (`<= 200`) on `/api/catalog/graph/search`.
- **Align PostgreSQL Manifestation FTS, Multi-Expression Work Facets & Offline Collection Filtering (`app/core/search_service.py`, `app/core/data_manager.py`, `frontend/app/collection/page.tsx`):** Include `MIXED_MEDIA_FORMAT_CATEGORIES` (`cd_dvd_combo`) in `_pg_manifestation_fts()`, prevent double-counting multi-expression `Work`s across primary/secondary categories in `DataManager.get_faceted_stats()`, and enforce `expressionKindFilters` + `cd_dvd_combo` category matching inside Capacitor offline mode in `frontend/app/collection/page.tsx` (clearing the `react-hooks/exhaustive-deps` warning).
- **Tighten `SemanticLinks` `WRITE_METADATA` RBAC, Cover Fallback & Ontology/Docs Polish:** Gate `"Scan External LOD"` behind `canEdit` inside `SemanticLinks` and pass `PermissionName.WRITE_METADATA` from `ItemSidebar` (and entity detail callers); pass `llm_permissions={}` in `upload_cover()` synchronous fallback; remove `rdfs:subPropertyOf frbroo:R2_is_derivative_of` from `iqoqo:sourceWork` in `docs/ontology/iqoqo.ttl`; add `USE_DOCKER=true` support to `make reconcile-cross-media`; guard nullable `cand.confidence`, add source/target swap & `"Cancel"` label in `WorkLinkReviewer`; localize residual `"Help Request:"`/`"Requests"` strings in `ItemActions`; align E2E test title in `faceted_catalog_sync.spec.ts`; and update `docs/CHANGELOG.md` and Blueprint 8 SVG (`7` edge categories).
