## Why

A `/tech-comm-expert` audit of `README.md`, `docs/*.md`, `frontend/lib/help-articles.ts`, and all 12 SVG architecture diagrams against the `v1.2.0` codebase identified significant bloat/redundancy (~11,825 documentation lines), stale `v0.x`–`v1.0` prose, missing `v1.1.1`–`v1.2.0` feature docs, a real backup key-directory mismatch (`data/keys/` vs `data/federation_keys/`), and architectural drift across **10 of 12** SVG blueprints (`01`–`08`, `10`, `12`):

1. **Redundant & Oversized Docs:** `ARCHITECTURE.md` (1199L), `INSTALL.md` (1074L), `API.md` (1013L), `OPERATIONS.md` (610L), `SEMANTIC_WEB.md` (543L), and `COVERS_SETUP.md` (296L) duplicate backup/restore steps, SPARQL/LOD curl blocks, format curation, Automatic1111 setup, and local dev commands across 3–5 files, while carrying historical `0.8.0` / PG 18 runbooks inline.
2. **Stale & Contradictory Facts:** Multiple docs still say `Redis 8` instead of `Valkey 8`, `ARCHITECTURE.md` omits `federation`/`config` DB schemas and quotes outdated Work merge FK counts (`13`/`14` vs actual `19`/`20`), `CONTRIBUTING.md` still recommends Bootstrap instead of Tailwind CSS v4 + shadcn/ui and legacy `session.query()`, `BACKUPS.md` misses native `S3_BUCKET_ARCHIVE` / `--archive` (`C163`) and lists `data/federation_keys/` while `app/core/federation_keys.py` uses `data/keys/`, `COVERS_SETUP.md` & `auth-setup.md` have broken ``\`\`` escapes and truncated Section 6, `INSTALL.md` & `item_statuses.md` have split table headers, and `help-articles.ts` claims Oxigraph instead of RDFLib `sparql-runner` + old `1..2` graph depth / `6` edge categories.
3. **Architecture SVG Drift (`10/12` diagrams):** Only `09` and `11` match `v1.2.0`. Diagrams `03` (wrong DB schemas/table counts), `08` (contradictory `depth 1..4` vs `1|2`, missing `derivatives` category & `C164` canonical `lod:<digest>`), `10` (missing `C156` multi-server registry + wrong cache wipe claim), and `12` (missing `preview-reconcile`, native S3/Glacier `S3_BUCKET_ARCHIVE`, `data/keys/` mismatch) have major drift, and `01`, `02`, `04`, `05`, `06`, `07` have minor `v1.1.2`/`v1.2.0` omissions.
